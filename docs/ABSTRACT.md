# ABSTRACT

## AN AUTONOMOUS CREDIT RISK ASSESSMENT AND EXPLAINABLE AI SYSTEM WITH HYBRID MULTI-BANK POLICY RAG ENGINE
### (Loan-IQ)

Loan-IQ is an intelligent, autonomous credit risk assessment and policy decision engine designed to ensure accurate, transparent, and compliant loan underwriting. The system continuously evaluates applicant profiles in real time, predicts credit default probabilities using advanced machine learning ensemble techniques, and provides instant risk scoring without manual underwriting bottlenecks.

It combines a 2-tier Stacking Ensemble Classifier (XGBoost, LightGBM, CatBoost, Random Forest with an ANN Meta-Learner), SHAP explainable AI attributions, and a specialized multi-bank policy compliance module. When a loan application is processed, Loan-IQ evaluates financial obligations (FOIR, LTV, EMI), checks hard baseline bank rules across major institutions (SBI, HDFC, ICICI, IOB, Canara, and RBI guidelines), and isolates policy violations. In parallel, it utilizes a Hybrid RAG Engine combining dense FAISS vector search and sparse BM25 keyword retrieval with Reciprocal Rank Fusion (RRF) re-ranking to deliver precise, context-aware policy explanations.

The system uses AI to predict creditworthiness, provide local SHAP feature impact attributions for regulatory transparency, and generate actionable improvement recommendations for rejected applicants. Featuring a modern, high-performance web dashboard and interactive AI policy assistant, Loan-IQ provides real-time risk visualization, financial ratio metrics, and audit-ready decision rationale. Loan-IQ aims to create a resilient, secure, and explainable financial technology infrastructure for automated loan processing.
