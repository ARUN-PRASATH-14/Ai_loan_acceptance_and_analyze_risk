## 1️⃣ `models/` (Machine Learning Pickles & Explainability Maps)

### 🎯 Purpose
Stores the serialized binary artifacts generated by `scripts/train_model.py`. These files are loaded at startup by `app.py` to run instant model inference and compute SHAP explanations.

### 📄 Key Files
1. **`loan_model.pkl` (~2.0 MB)**: The trained **Stacking Ensemble ML Classifier** (XGBoost, LightGBM, CatBoost, Random Forest + MLP Meta-Learner).
2. **`preprocessor.pkl` (~3.3 KB)**: The fitted `ColumnTransformer` combining `StandardScaler` for numerical attributes and `OneHotEncoder` for categorical variables.
3. **`threshold.pkl`**: Stores the optimal credit risk decision cutoff (`0.50`).
4. **`feature_names.pkl`**: Array of expected input features before pre-transformation.
5. **`encoded_feature_names.pkl`**: Post-transformation feature labels used by `shap.TreeExplainer` to plot local waterfall attributions.

---

## 2️⃣ `knowledge_base/` (Raw Policy & Regulatory Documents)

### 🎯 Purpose
Serves as the ground-truth document store containing authentic bank underwriting manuals and RBI Master Directions.

### 📄 Key Files
* **`sbi_kyc_loan_policy_manual.txt`**: State Bank of India income, CIBIL (700+), FOIR (65%), and LTV rules.
* **`hdfc_kyc_loan_policy_manual.txt`**: HDFC Bank personal and home loan underwriting criteria.
* **`icici_kyc_loan_policy_manual.txt`**: ICICI Bank credit score cutoffs and NTC restriction rules.
* **`iob_kyc_loan_policy_manual.txt`**: Indian Overseas Bank take-home pay and annual income thresholds.
* **`canara_kyc_loan_policy_manual.txt`**: Canara Bank 600+ CIBIL leniency guidelines.
* **`rbi_master_direction_kyc_aml_2025_2026.txt` & `rbi_circular_2025.txt`**: Official Reserve Bank of India guidelines on KYC, Officially Valid Documents (OVDs), V-CIP, and fair lending practices.

---

## 3️⃣ `rag_index/` (FAISS & BM25 RAG Search Index)

### 🎯 Purpose
Stores the pre-indexed vector embeddings and keyword indices generated by `scripts/build_rag.py` to enable **sub-10ms hybrid policy retrieval** during chatbot queries.

### 📄 Key Files & Folders
1. **`faiss_index/` (Folder)**: Contains the **FAISS (Facebook AI Similarity Search)** dense vector database index built using 384-dimensional normalized embeddings from `all-MiniLM-L6-v2`.
2. **`bm25_index.pkl`**: Serialized **BM25Okapi** sparse keyword index used to perform BM25 term-matching in the Reciprocal Rank Fusion (RRF) re-ranking pipeline.

## 🎓 Expected Review 2 Defense Questions

### Q1: "How are your ML models and RAG indices kept separate?"
> **Answer**: `models/` stores serialized ML pickles (`loan_model.pkl`, `preprocessor.pkl`) generated by `scripts/train_model.py` for risk prediction. `rag_index/` stores the FAISS vector database and BM25 index generated by `scripts/build_rag.py` from raw text in `knowledge_base/` for policy RAG.

### Q2: "What is the purpose of the `dist/` folder?"
> **Answer**: `dist/` contains the production-compiled single-page Web application built with Vite and React (`npm run build`). `app.py` serves `dist/index.html` directly so that users access a unified full-stack application on port 5000.

### Q3: "Why do you have both `faiss_index/` and `bm25_index.pkl` inside `rag_index/`?"
> **Answer**: `faiss_index/` handles **Dense Semantic Search** (understanding context and synonyms), while `bm25_index.pkl` handles **Sparse Keyword Search** (matching exact terms like 'SBI', 'CIBIL', or 'OVD'). Combining both via Reciprocal Rank Fusion (RRF) delivers maximum retrieval accuracy.
